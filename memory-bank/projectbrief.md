# FinTrack - Проектно описание

## Обща информация
**Име на проекта:** FinTrack  
**Тип:** React Native мобилно приложение за финансово управление  
**Платформи:** iOS и Android  
**Език:** TypeScript с React Native  

## Основна цел
Създаване на красиво, модерно и изпипано финансово приложение с дизайн в стил Apple, което предоставя пълно управление на личните финанси с гамификация елементи.

## Ключови функционалности
- **Управление на транзакции** - добавяне, редактиране, категоризиране
- **Бюджетиране** - създаване и проследяване на бюджети
- **Финансови отчети** - графики и анализи
- **Сканиране на разписки** - автоматично добавяне на транзакции
- **Финансово здраве** - оценка и препоръки
- **Гамификация** - постижения, мисии, нива
- **Симулации "Какво ако"** - финансово планиране
- **Гласов асистент** - гласово управление

## Дизайн изисквания
- **Стил:** Apple-подобен - минималистичен, чист, елегантен
- **Качество:** Много красив, модерен и изпипан
- **Анимации:** Средно ниво - фини микроинтеракции и плавни преходи
- **Модерни елементи:** Градиенти, стъклени ефекти, закръглени карти, модерни бутони
- **Производителност:** Позволени са сложни визуални ефекти

## Технически стек
- React Native 0.79.2
- TypeScript
- React Navigation
- React Native Chart Kit
- React Native SVG
- Async Storage
